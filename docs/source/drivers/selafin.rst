================================================================================
Selafin/Serafin -- TELEMAC outputs format
================================================================================

.. shortname:: TELEMAC

.. built_in_by_default::

MDAL supports reading of the _Selafin/Serafin format generated by TELEMAC_.

On save, MDAL computes a geometric IPOBO boundary-numbering array (contours
walked from their south-west node, external contours counter-clockwise,
islands clockwise) instead of writing zeros; when re-saving an unmodified
Selafin mesh, the IPOBO array of the source file is preserved.

.. _TELEMAC: http://www.opentelemac.org/
.. _Selafin/Serafin: https://gdal.org/drivers/vector/selafin.html
